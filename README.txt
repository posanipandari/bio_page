# Link Bio Page

A mobile-responsive Link-in-Bio page inspired by the supplied screenshot.

## Files

- index.html
- style.css

## Run

Open `index.html` in a browser.

## Customize

Change the URLs in `index.html` for:
- Portfolio
- GeeksforGeeks
- LeetCode
- GitHub
- YouTube
- LinkedIn

The icons use Font Awesome from a CDN, so an internet connection is needed for the icons to load.
